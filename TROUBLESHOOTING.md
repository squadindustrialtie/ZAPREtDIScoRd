# Диагностика проблем — discord-zapret

Этот документ дополняет исходный README и не заменяет его. Проверяйте по одному параметру за раз: DNS, стратегию, приложение и состояние служб.

## Базовая последовательность

1. Проверьте, открывается ли ресурс без активной стратегии.
2. Убедитесь, что используется актуальный релиз `discord-zapret`.
3. Проверьте Secure DNS согласно README.
4. Запустите Run Diagnostics через `service.bat`, если этот пункт доступен.
5. Остановите текущую стратегию и протестируйте другую.
6. Запишите результат, версию Windows и тип подключения.

## Discord: Connecting, RTC и голос

- Проверьте Discord в браузере по адресу https://discord.com/app.
- Если браузер работает, а приложение нет, закройте Discord и выполните рекомендованную README очистку кэша.
- Для Canary и Development используйте соответствующий пункт диагностики, если он присутствует.
- Если текст работает, но голос — нет, проверьте UDP/RTC и параметры Game Filter.
- После переключения Game Filter перезапустите стратегию, если этого требует README.

## YouTube: видео не запускается или буферизуется

- Проверьте тот же ролик в другом браузере.
- Временно отключите блокировщик рекламы/расширения только как диагностический тест, затем верните их настройки.
- Проверьте Secure DNS и другую стратегию.
- Медленная загрузка не всегда означает DPI-фильтрацию: проверьте скорость и стабильность обычного соединения.

## Telegram: веб и Desktop

- Для Telegram Web README упоминает Update Hosts File; повторите проверку после обновления hosts.
- Для Telegram Desktop README не гарантирует работу через Zapret и предлагает отдельный локальный/публичный прокси.
- Не считайте исправление веб-версии доказательством исправления Desktop.

## Ошибки WinDivert и антивируса

WinDivert может определяться защитными программами как сетевой инструмент. Проверьте подпись/контрольную сумму и источник файла. Не отключайте защиту полностью и не добавляйте сомнительные файлы в исключения без проверки.

## Служба не устанавливается или не запускается

- Проверьте запуск с достаточными правами.
- Посмотрите Check Status и Run Diagnostics, если они есть.
- Не запускайте параллельно несколько `general*.bat`.
- Используйте Remove Services через меню проекта для удаления службы.

## Что приложить к отчёту

Укажите точную ошибку, версию Windows, имя стратегии, тип сети (домашняя/мобильная/корпоративная), какой сервис тестировали и результат браузерной проверки. Не прикладывайте токены, пароли, личные IP или другие секретные данные.
