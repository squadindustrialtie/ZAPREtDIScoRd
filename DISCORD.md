# Discord Zapret / Zapret Discord — подключение, voice, RTC и Windows

Материал для запросов `discord zapret`, `zapret discord`, `discord zapret github`, `скачать discord zapret`, `скачать zapret discord`, `Discord Windows`, `Discord Connecting`, `Discord RTC` и `Discord voice не работает`. Документ относится к репозиторию `discord-zapret` и дополняет исходный README, не заменяя его.

## Когда искать решение по Discord Zapret

Эта инструкция подходит для диагностики ситуаций, когда Discord долго остаётся на Connecting, не загружает каналы, не подключается к голосовой комнате или показывает RTC Connecting. Текстовый чат, веб-версия, настольное приложение и голосовой канал следует проверять отдельно: успешное открытие `discord.com/app` ещё не подтверждает, что voice/RTC работает.

Пользователи описывают похожие ситуации по-разному: «Дискорд не работает», «Дискорд не подключается», «Discord не заходит», «Discord voice connection error», «Discord RTC error», «Discord голосовой чат не работает», «Discord не грузит сообщения». Это разные симптомы одной сетевой диагностики, а не отдельные гарантированные функции программы.

## Порядок проверки Discord

1. Проверьте обычное соединение и откройте веб-версию Discord.
2. Сравните работу веб-версии и приложения Windows.
3. Проверьте Secure DNS / DNS-over-HTTPS согласно исходному README.
4. Выберите одну стратегию Zapret, проверьте текстовый чат, затем голосовую комнату.
5. При зависании Connecting используйте Run Diagnostics из `service.bat`, если этот пункт есть в конкретной сборке.
6. При проблемах приложения выполните рекомендованную исходным README очистку кэша. Перед этим полностью закройте Discord.
7. Функцию Update Hosts File используйте только в соответствии с исходной инструкцией; она упоминается в связи с голосовым подключением.

## Discord на Windows 10 и Windows 11

Поиск может использовать варианты `discord zapret windows 10`, `discord zapret windows 11`, `discord voice fix windows`, `discord rtc connecting fix`, `Discord app не подключается`, `Discord web не работает`. В этой сборке используются Zapret и WinDivert для Windows. Она не является альтернативным Discord-клиентом и не содержит сервер Discord.

## Что проверить, если Discord всё ещё не работает

Сравните результат с выключенной и включённой стратегией, проверьте другую сеть и браузер, не меняйте одновременно DNS, стратегию и Game Filter. Если не работает только голос, отдельно проверьте UDP/RTC. Если не работает только приложение, отдельно проверьте кэш и веб-версию.

## Ограничения

Результат зависит от сети, провайдера, DNS, маршрутизации, приложения и выбранной стратегии. Discord Zapret не гарантирует подключение во всех сетях, не является VPN и не заменяет официальный клиент Discord.
