YouTube Zapret / Zapret YouTube — zapretdiscord

Для чего эта страница

Отдельный материал о диагностике загрузки YouTube и воспроизведения видео в Windows. Поисковые варианты: YouTube Zapret, Zapret YouTube, YouTube не работает, YouTube медленно грузится, YouTube buffering, YouTube playback fix.

Проверки по порядку

  1. Откройте YouTube в другом браузере.
  2. Проверьте Secure DNS / DNS-over-HTTPS.
  3. Временно отключите блокировщик рекламы и расширения как тест: исходный README отдельно отмечает, что блокировщики могут влиять на работу YouTube.
  4. Проверьте другую стратегию Zapret, запуская только одну за раз.
  5. Сравните загрузку страницы и воспроизведение видео — это разные этапы проверки.

Что не следует обещать

Сборка не гарантирует увеличение скорости YouTube и не гарантирует работу в любой сети. Медленная загрузка может быть связана с провайдером, DNS, браузерными расширениями, самим сервисом или маршрутом.
