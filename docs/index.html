Важная информация

  • Читайте исходные README до запуска программ.
  • Не запускайте несколько стратегий одновременно, если инструкция этого не предусматривает.
  • WinDivert может вызывать предупреждения защитного ПО; проверяйте происхождение и контрольные суммы.
  • Для Telegram Desktop может понадобиться отдельный прокси; работа через Zapret не гарантируется.
