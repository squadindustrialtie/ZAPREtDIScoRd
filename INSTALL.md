# Установка Discord Zapret на Windows

Эта инструкция относится к архиву `discord-zapret` (тег релиза `1.10.4`). Сборка использует Zapret/WinDivert. Перед запуском прочитайте исходный `README.md` и проверьте состав архива.

## 1. Подготовка

1. Убедитесь, что используете Windows 10 или Windows 11, как указано в исходной документации.
2. Скачивайте ZIP только со страницы Releases именно того репозитория, который собираетесь использовать.
3. Проверьте имя файла и, если доступны, контрольные суммы из комплекта.
4. В свойствах загруженного архива проверьте состояние блокировки Windows. Снимайте блокировку только при доверии к источнику.
5. Распакуйте архив в короткую папку без кириллицы и специальных символов, например `C:\Tools\Zapret`.
6. Ознакомьтесь с `Files/README.md` перед запуском любых сценариев.

## 2. Secure DNS

В README рекомендуется включить Secure DNS / DNS-over-HTTPS в браузере. В Windows 11 эту настройку также можно задать на уровне системы. Выберите DNS-поставщика, который доступен из вашей сети. Изменение DNS не гарантирует обход ограничений и не заменяет проверку маршрута.

## 3. Проверка стратегии

1. Закройте приложения, которые планируете тестировать.
2. Откройте нужный `general*.bat` из распакованного комплекта с правами администратора, если это требуется сценарием.
3. Проверяйте одну стратегию за раз.
4. После запуска откройте целевой ресурс и отдельно протестируйте функции приложения: веб-страницу, видео, голосовой чат или Telegram Web.
5. Если стратегия не помогает, остановите её и проверьте следующую. Не запускайте несколько стратегий одновременно без прямого указания в README.

## 4. Службы и диагностика

Если в архиве присутствует `service.bat`, в README описаны пункты Install Service, Remove Services, Check Status, Game Filter, Update Hosts File и Run Diagnostics. Набор доступных пунктов зависит от версии. Используйте меню и не выполняйте незнакомые команды вручную.

## 5. Проверка сервисов

- **Discord:** отдельно проверьте вход, текстовые каналы и голосовое подключение/RTC.
- **YouTube:** проверьте загрузку главной страницы и воспроизведение видео; при проблеме с воспроизведением проверьте расширения и блокировщик рекламы.
- **Telegram Web:** если доступна функция Update Hosts File, примените её по README и повторите проверку.
- **Telegram Desktop:** README предупреждает, что работа не гарантируется; может понадобиться отдельный локальный или публичный прокси, например tg-ws-proxy.

## 6. Откат

Если возникли сетевые проблемы, остановите активную стратегию и используйте предусмотренную в `service.bat` функцию удаления службы. При сомнениях верните исходные настройки DNS/сети и обратитесь к документации upstream.

> Не отключайте антивирус или защиту Windows целиком ради запуска неизвестного файла. WinDivert — сетевой драйвер; проверяйте происхождение и контрольные суммы компонентов.
